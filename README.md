# 🎲 Snake and Ladder Game (SDL2 + C++)

A simple 2D Snake and Ladder game built using **C++** and the **SDL2 library**. This project demonstrates fundamental game development principles and modular programming using object-oriented design.

---

## 🧠 What I Learned

- Effective use of **modularization** and class-based architecture in C++
- Working with the **SDL2** library for graphics and game loop management
- Managing resources and rendering textures
- Basic state handling for game mechanics

---

## 🚧 Current Status & Future Improvements

While the core functionality is working, the game is still **incomplete**. Here are some pending improvements and ideas for future development:

- 🎬 Starting and winning animations
- 🔁 Game reset logic or prompt to restart
- 🧍‍♂️ Single-player mode
- 🌀 Player movement animation
- 🧾 In-code comments for clarity and maintainability

Although not all features are guaranteed to be added, the game is already **functionally complete** as a basic Snake and Ladder game.
